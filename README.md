一个**开箱即用**的网页版历史知识对战场——**两位同学同屏对战**，随机抽题、实时计分，结束后自动生成得分曲线与知识点掌握分析。适合课堂分组对抗、课后小组复习、家庭亲子互测。

在线体验：**https://johnlicheng.github.io/**

---

## ✨ 功能特点

| 特点 | 说明 |
| --- | --- |
| 🧑‍🤝‍🧑 **双人同屏对战** | 左右分屏，两位玩家各自独立作答、各自独立的"下一题"按钮，互不影响 |
| 🎲 **随机抽题不重复** | 从 100 道题库中自动洗牌抽题，每次对局题目都不一样 |
| 📚 **按章节抽题** | 题目按教材单元分类，可自由勾选章节范围，全册抽题也可 |
| ⏱️ **进度与得分实时更新** | 作答即判正误，双方得分与进度一目了然 |
| 📊 **详细成绩分析** | 结束后自动生成：胜负、得分/答对数/正确率、得分曲线、逐题解析 |
| 📖 **知识点掌握诊断** | 按单元统计正确率，自动标出薄弱环节并提示"建议复习" |

## 🎮 怎么玩

1. **进入对局**——左右两位同学分别输入姓名，选择题目数量（10/12/15/20）与章节范围，点"开始对战"。
2. **各自作答**——每人轮流看自己的题目，点选 A/B/C/D；作答后立刻显示对错、正确答案、解析、出处。
3. **点"下一题"**——每人有自己独立的"下一题"按钮，完成后双方自动进入结算页。
4. **看成绩**——比拼得分、正确率，查看得分曲线与自己薄弱的知识单元，查缺补漏。

> 💡 键盘快捷：左侧选手用 `1` `2` `3` `4` 选题，右侧选手用 `7` `8` `9` `0` 选题。

- 纯前端实现，**零依赖、零构建**，不需要安装任何环境，适合学校机房/教室使用。
